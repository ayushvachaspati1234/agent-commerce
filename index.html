Four primitives. One rail.

Everything an agent needs to transact safely, exposed as a clean API.

Agent identity & verification

Every agent gets a signed credential bound to its operating company. Counterparties verify it in one call — before a single token of negotiation.

Spend mandates

Set per-transaction, daily, and category limits in policy code. The rail enforces them — an agent literally cannot exceed its mandate, even if compromised.

Escrowed settlement

Funds lock at agreement and release on delivery confirmation — settled in under 400 ms. No counterparty risk, no 3-day ACH limbo.

Machine-readable receipts

Every transaction emits a signed, structured receipt with the full negotiation trail. Disputes resolve programmatically against the recorded terms.
